zeckon / claude-plugins
history

Every Claude turn committed to a shadow git repo you can browse and restore from.

    Install

    /plugin marketplace add zeckon/claude-plugins
    /plugin install history@zeckon-claude-plugins

    Opt in per project with /history:enable. Needs git and python3.

    In the video

    How each turn becomes a commit in a shadow repo next to your project's own .git, how to opt a project in, the two shell hooks that do the work, what a commit holds, and how to look back and restore a file.
